❓ C'est quoi une période ?

Un phénomène est périodique quand il se répète identique à lui-même, encore et encore : le balancier repasse sans cesse par les mêmes positions.

Sur le signal, on voit donc le même motif se répéter (un motif par couleur ci-dessus). La période T est la durée d'un motif : le temps qui sépare deux instants où le phénomène se retrouve exactement dans le même état, par exemple deux sommets qui se suivent.

Pour la mesurer à l'oscilloscope : place le curseur A sur un point du signal (un sommet), puis le curseur B sur le point identique suivant. L'écart Δt affiché est la période.
