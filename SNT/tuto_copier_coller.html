📊 Comment tracer une courbe à partir des résultats SQL ?

1

Exécuter la requête SQL dans le client et vérifier les résultats.

anneetemp_moy
195012.5
195112.7
195212.4
……
2

Copier le tableau en cliquant sur le bouton :

📋 Copier la table ← cliquer ici

Le tableau est copié avec les en-têtes de colonnes.

3

Dans le tableur, faire un clic droit sur la cellule A1, puis choisir :

⬇ Importer ici…
🗑 Supprimer la ligne
4

Coller le contenu copié dans la zone de texte (Ctrl+V), puis cliquer OK — Importer.

annee   temp_moy
1950    12.5
1951    12.7 …
5

Assigner les axes en cliquant sur les bandeaux colorés en haut de chaque colonne :

annee
X
temp_moy
Y1

Bandeau bleu = axe X  |  Bandeau vert = axe Y1

6

La courbe s'affiche automatiquement à droite. Observer la tendance et conclure.

7

Télécharger la courbe en cliquant sur le bouton :

← cliquer ici

Le fichier JPG est téléchargé. Déposez-le ensuite dans la cellule de réponse Moodle.
